## 維護方式

- 功能與操作寫進對應的主文件，不為每輪工作另開同類文件。
- 未完成工作只列在「現況與待辦」；平台逐站關卡只列在平台接通主表。
- 文件描述現況。被取代的系統與做法不留在這些文件裡，要查就看 git 歷史、遷移計畫與 ADR；`plans/` 與 `adr/` 是當時的紀錄，不改寫。
- 這個 repo 是公開的：個人 email、真名、IP、費率、個別帳號進度不寫進文件。
- 文件與程式不一致時以程式為準，並修正文件。
