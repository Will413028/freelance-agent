# 目前功能與使用方式

更新日期：2026-11-15。描述 2026-11-06 起正式運作的系統。

這個專案現在做一件事：**每天把多個平台的兼職機會收進同一份清單，依個人條件排序，讓本人收藏或略過。** 應徵回原平台自己完成。

## 功能總覽

| 功能 | 入口 | 狀態 |
|---|---|---|
| 每日自動收案 | 背景排程，台灣時間 09:00 後 | 運作中；各來源覆蓋不同 |
| 職缺清單、分頁、四種檢視 | `/` | 可用 |
| 職缺詳情、匹配理由、待確認資訊 | `/jobs/[id]` | 可用 |
| 收藏、取消收藏、略過、恢復待看 | 職缺詳情頁的按鈕 | 可用 |
| 競賽清單（依投稿截止排序，不評分）、競賽詳情與收藏／略過 | `/?type=contest`、`/jobs/[id]` | 程式完成，待部署（機會類型計畫步驟 5b） |
| 同職缺通知內容差異 | 職缺詳情頁 | 可用 |
| 來源狀態與最近一次每日收案 | `/sources` | 可用 |
| 篩選設定 | `/settings` | 可用 |

**目前沒有的功能**（舊系統有、現行系統沒有畫面，資料保留在資料庫的歷史表）：

- 每日摘要 Email：已停用，程式裡沒有寄信功能。
- 人工投案紀錄、每週統計、待跟進提醒。
- 客戶與聯絡人。
- 提案模板與草稿版本。
- 外部送出（Email／Freelancer 投案通道）。
- 清單的關鍵字搜尋，以及依平台或合作型態篩選。

要用到時再重新設計（遷移計畫決定 D22、D23）。

## 1. 每日收案

- 每天台北時間 09:00 後收集一次已接通的來源：公開 API、RSS、公開頁面，以及指定的職缺通知信。
- 增量保存：同一內容重讀不重複新增。
- 各來源分別回報結果，一個來源失敗不影響其他來源。
- 一天只跑一次。當天有來源失敗時不會重跑，隔天再讀。

哪些平台已接入、讀取限制與下一個關卡，查[平台接通主表](platform-connectivity.md)。研究名單不等於已接入，有限讀取也不代表全站覆蓋。

## 2. 職缺清單（`/`）

- 四種檢視：**待看**（候選）、**收藏**、**已略過**、**全部**。
- 候選在前，依推薦分排序；每頁 50 筆，有上一頁／下一頁。
- 每張卡片顯示來源、職稱、公司、合作型態、工作內容、報酬、每週工時、匹配分類、推薦分、發布新鮮度，以及評估狀態：條件吻合／條件待確認／條件不符／通知內容有差異。
- 資料缺漏時顯示「待確認」，不把未知條件當作符合，也不把 remote 當成全球都能承接。

## 3. 職缺詳情（`/jobs/[id]`）

- 報酬、每週工時、地點與依據、台灣資格、推薦分與資訊完整度、新鮮度。
- 匹配理由、排序依據、完整工作內容、待確認資訊清單。
- 原始職缺連結，供本人回原平台核對有效期限、資格與需求。
- 同一職缺收到內容不同的通知時，各份內容都保留，並列出差異欄位。系統不判斷哪一份比較新：轉寄時間不是證據。請對照原始職缺確認。

### 收藏與略過

- 「收藏職缺／取消收藏」與「略過／恢復待看」。
- 收藏只表示值得評估，不代表已投案。略過的職缺離開待看清單。
- 操作時若職缺內容或狀態在你開頁之後變過，會提示重新載入，不會用舊畫面覆蓋新狀態。

## 4. 來源狀態（`/sources`）

- 最近一次每日收案：日期、狀態（執行中／完成／部分來源或處理失敗）、起訖時間、原因。
- 每個來源的狀態：最近讀取成功、部分資料取得、讀取失敗或不完整、尚未接通；以及檢查時間與當次的讀取、寫入、新增筆數與拒收或隔離數。
- 讀取成功代表最近一次已配置範圍的結果。尚未接通或讀取不完整的來源不等於沒有職缺。
- 每日收案顯示「部分來源或處理失敗」是常態：只要有一個來源失敗就是這個狀態，其他來源的職缺照常收進來。

## 5. 篩選設定（`/settings`）

- 每週工時上限：預設 30 小時，可設 1–168，留空表示不限。
- 固定專案最低預算（TWD）：預設 3,000。
- 專長分類：AI agent、AI 整合／自動化、後端／API、全端 MVP，至少選一種。
- 儲存後清單依新設定重新評估與排序。先前因為舊設定而排在後面的職缺不會遺失。
- 未提供工時或報酬的機會保留並標示待確認；時薪與外幣不套固定專案的 TWD 門檻。

## 建議日常使用流程

**開清單看待看 → 進詳情核對條件 → 收藏或略過 → 回原平台投案。**

系統沒有配額、沒有自動投案，也不會提醒跟進。

## 如何開啟

用瀏覽器開正式網址，以 Vercel 帳號登入後才看得到（Vercel Authentication）。沒有公開頁面，也不需要 SSH 或本機程式。

本機開發與驗證見 [README](../README.md)。
